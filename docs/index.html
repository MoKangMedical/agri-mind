🚀 快速体验

# 安装
pip install agri-mind

# 查询种植指南
agri-mind query 水稻
agri-mind query 小麦

# 启动 Web 服务
agri-mind serve 8000

# API 接口
GET /api/crops              # 作物列表
GET /api/crops/{name}       # 种植指南
GET /api/crops/{name}/advice?month=4&zone=华东  # 当前建议
POST /api/diagnose          # 病虫害图片诊断
